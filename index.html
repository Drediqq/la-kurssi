2. What is Nginx, and what does it do on this server?

Nginx is a very popular high performance and lightweight webserver which has multiple applications including serving static web pages like in this case.

3. Which commands did I use?

List the commands for installing Nginx, checking its status, and enabling automatic startup. Explain what each does.

Updates local packagelist AND installs nginx and vim, which is also important (becouse vim was not installed for some unknown reason) 

sudo apt update && sudo apt install nginx vim

Starts nginx, at this point nginx runs and serves page, but it does not survive reboot

sudo systemctl start nginx

"enabling" nginx(.service) makes nginx persistent (so it survives reboot) 

systemctl enable nginx

Shows nginx current runtime status

systemctl status nginx
