Answers to questions

What database was used?

Mariadb in a docker container

How does this counter save data?

Python script runs with flask in a docker container, which then modifies a table in mariadb which is running in another docker container as mentioned before. nginx now serves 2 static pages and this flask application.

Script first creates a table if it doesn't exist into a database specified in secret environment file. When flask is "triggered" it sends signal to the script and then it runs a function which increases count in db by one, when page is loaded. After that script returns a slightly modified html file back to flask which in return renders it

What happens when virtual machine is rebooted?

Docker containers spin back up due to this line in the docker-compose: "restart: unless-stopped". Database keeps its data aswell due to: "volumes:mariadb_data:/var/lib/mysql"
